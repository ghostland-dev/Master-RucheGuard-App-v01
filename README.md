# RucheGuard

Beekeeping management front-end: hives, production, treatments and statistics.

## Features

- Hive and beekeeper management
- Production and treatment tracking
- Subscriptions, users and statistics pages

## Tech Stack

- HTML/CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/rucheguard.git
cd rucheguard
# open index.html in your browser, or serve the folder:
npx serve .
```
